# agents

Монорепозиторий агентов. Каждый агент — отдельный проект в своей папке
со своими `CLAUDE.md`, `README.md`, `PORTS.md` и `docker-compose.yml`.

| Проект | Описание |
|---|---|
| [lab_manager](lab_manager/) | Telegram-менеджер лабораторных работ: раскладывает задания по папкам, синхронизирует с Яндекс Диском, готовит промпты для исполнителя |
| [telepathy](telepathy/) | «Телепатия» для пары: сообщает обоим, когда мысли партнёров совпали по смыслу (e5 + LLM-судья); живёт в общем боте за шлюзом lab_manager |
