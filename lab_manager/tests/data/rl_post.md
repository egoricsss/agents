📎 Коллеги, публикую задание на ЛР 3.

Данная лабораторная работа посвящена обучению с подкреплением (RL), предполагает разработку индивидуального решения и также состоит из 2 этапов.

✔️ Этап 1
На данном этапе необходимо установить и согласовать в личном порядке:
🟢 задачу, которую вы собираетесь решать с помощью RL
🟢 модель, которую вы выбираете для дообучения на поставленную задачу; а также аргументы в сторону ее выбора
🟢входные и выходные данные модели, их формат и требования к ним; источник данных для обучения (где возьмете данные, на которых будете обучать)
🟢 функцию наград и штрафов
🟢этап улучшения: предполагается реализация двух вариантов решения задачи и их сравнение
🟢метрики оценки качества решения для анализа результатов (включает оценки эффективности обучения и ответов обученной модели)
🟢подход к заданию среды для обучения
🔘Запрещено использовать в качестве задачи игры библиотеки "gymnasium".

✔️Этап 2
Данный этап подразумевает реализацию согласованного плана исследования: решение поставленной задачи выбранной моделью с помощью ее обучения / дообучения с подкреплением в заданной среде, а также оценка результатов выбранными метриками.
Этап оформляется в Jupiter notebook.


Оба этапа оцениваются по шкале {0,1,2}. 2 балла ставится за работу, сданную в срок без существенных вопросов (все пункты задач выполнены самостоятельно и аргументированно). Первый этап пересдается только в случае некорректного содержания большой части пунктов, в остальных случаях даются рекомендации по уточнению, ставится 1 балл и студент допускается до сдачи 2го этапа. Этап 2 оценивается по соблюдению заявленных границ исследования на первом этапе и качества подготовленного ноутбука решения (в том числе, с точки зрения полученных метрик оценки модели)
